# 앱 버전 관리

버전은 날짜 없이 `major.minor.patch` 형식으로 관리하며 `0.0.1`부터 시작합니다.
우측 하단 상태 표시줄은 `package.json`의 버전을 표시합니다.

```sh
pnpm version:set 0.0.2
```

이 명령은 `package.json`, Tauri 설정, Cargo 설정과 Cargo 잠금 파일의 앱 버전을 함께 변경합니다.
버전을 올린 뒤 앱을 다시 빌드합니다. Git 커밋이나 태그는 자동 생성하지 않습니다.
릴리스 태그는 `v0.0.2` 형식이며 기존 CI에서 태그와 앱 버전의 일치 여부를 검사합니다.
