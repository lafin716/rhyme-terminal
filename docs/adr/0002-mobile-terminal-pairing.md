# 선택한 네트워크 IP에서 모바일 터미널 페어링 제공

Date: 2026-09-07
Status: Accepted

## 배경

사용자는 Tailscale을 통해 모바일에서 기존 winmux 터미널을 보고 조작하고, 접속에 사용할 PC 네트워크 IP를 직접 선택하기를 요청했다. 이는 ADR 0001에서 제외했던 Mobile Companion 중 터미널 원격 접근을 새롭게 허용하는 결정이다.

## 결정

데스크톱 앱에서 선택한 로컬 IP에 HTTP/WebSocket gateway를 실행하고 QR 초대와 PC 승인을 통해 모바일 브라우저를 연결한다. gateway는 기존 winmuxd의 PTY를 구독하며 새 에이전트 실행 계층을 만들지 않는다. 모바일 화면은 앱 빌드에 포함한다.

gateway는 기본적으로 꺼져 있고 사용자가 시작한다. 창을 트레이로 숨겨도 유지하며 앱 종료 또는 서버 중지 시 연결과 인증을 폐기한다. 네트워크 인터페이스가 사라지면 다른 주소로 자동 확장하지 않는다.

기기 인증 후 제공하는 원격 기능은 세션 목록, 출력 구독, 입력에 한정한다. 모바일에서는 PTY 크기를 변경하지 않으며 PC와 동일한 터미널 크기를 스크롤하여 본다. 연결 실패 시 입력을 자동 재전송하지 않는다.

## 결과

- Tailscale을 통한 접근에 별도 winmux 중계 서비스가 필요하지 않다.
- 직접 IP 접속은 HTTP/WS를 사용한다. 전송 보호는 Tailscale 경로에 의존하며 일반 LAN 주소 선택 시 앱 자체 TLS는 제공하지 않는다.
- PC와 모바일에 Tailscale 연결이 있어야 해당 주소에 접근할 수 있고, 네트워크 접근 정책과 Windows 방화벽에서 선택한 포트가 허용돼야 한다.
- 인증은 서버 실행 수명에 묶인다. 앱/서버 재시작 후 다시 페어링한다.
- ADR 0001의 터미널 멀티플렉서 정체성을 유지하면서 모바일 제외 항목만 이 범위로 대체한다.
