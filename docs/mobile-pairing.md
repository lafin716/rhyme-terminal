# 모바일 터미널 연결

## 접속 순서

1. PC와 휴대폰에서 Tailscale을 연결한다.
2. winmux 설정의 **모바일 연결**에서 Tailscale 어댑터의 IP를 선택한다.
3. 포트(기본값 `43123`)를 확인하고 서버를 시작한다.
4. 휴대폰 카메라로 QR을 스캔한다. 초대는 2분 동안 유효하다.
5. 휴대폰과 PC에 표시된 확인 문자열을 비교하고 PC에서 승인한다.
6. 모바일에서 세션을 선택하고 출력 또는 입력창을 사용한다.

접속 주소는 `http://선택한-IP:포트/` 형식이다. QR에는 일회용 초대가 포함되므로 페어링에는 QR의 전체 주소를 사용한다. 만료된 초대는 PC에서 새로 발급한다.

## 동작

PC 창을 닫아 트레이로 숨겨도 연결은 유지된다. 앱을 완전히 종료하거나 모바일 서버를 중지하면 연결과 인증이 폐기되므로 다음 시작 시 다시 페어링한다. 개별 기기는 설정에서 접근을 해제할 수 있다.

모바일은 PC와 동일한 터미널 크기를 사용한다. 좁은 화면에서는 스크롤하여 내용을 확인한다. 한글은 입력창에서 작성 후 전송할 수 있고 Enter, Tab, Esc, Ctrl+C 보조키를 제공한다. 연결 중단 중에는 입력을 보내지 않으며 이전 입력을 자동 재전송하지 않는다.

## 접속되지 않을 때

- PC에서 선택한 IP가 현재 네트워크 어댑터에 존재하는지 확인하고 IP 목록을 새로고침한다.
- 같은 포트를 다른 프로그램이 사용 중이면 다른 포트를 선택한 후 시작한다.
- 휴대폰의 Tailscale 연결과 해당 PC 접근 권한을 확인한다.
- Windows 방화벽과 tailnet 접근 정책에서 선택한 포트로 접근할 수 있는지 확인한다. winmux는 방화벽/접근 정책을 자동 변경하지 않는다.
- 서버를 다시 시작했으면 새 QR로 다시 페어링한다.

직접 IP 모드는 HTTP/WS이며 Tailscale 경로를 통한 사용을 전제로 한다. 일반 LAN IP를 선택하면 앱 자체 TLS는 제공되지 않는다.

## 이전 버전에서 업데이트한 경우

이전에 실행해 둔 winmuxd는 새 모바일 연결 방식을 지원하지 않을 수 있습니다. 모바일 연결에서 데몬 업데이트 오류가 나타나면 진행 중인 터미널 작업을 먼저 마친 뒤 이전 데몬을 종료하고 새 빌드로 다시 실행하세요. 창을 트레이로 숨기는 것만으로 데몬이 갱신되지는 않습니다.


## 키보드 입력

세션을 선택한 뒤 터미널을 눌러 직접 타이핑할 수 있습니다. 아래 입력창에서는 한글이나 여러 줄을 작성한 뒤 전송할 수 있습니다. 연결이 끊기거나 세션을 전환하는 동안에는 입력을 차단합니다. 모바일 화면은 실행 파일에 포함되므로 입력 수정 적용 후에는 새 빌드로 앱을 다시 실행하고 재페어링하세요.
